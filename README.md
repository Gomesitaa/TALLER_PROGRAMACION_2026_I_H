# TALLER_PROGRAMACION_2026_I_H
## Project Overview

This repository contains the initial structure of a Java project created for the Software Engineering Programming Workshop 2026. The main objective of this project is to apply object-oriented programming principles, software engineering practices, Git version control, and the use of artificial intelligence tools such as GitHub Copilot.

The project follows a standard Java project structure inspired by the Maven directory layout while using Gradle as the build automation tool. This organization helps maintain a clean architecture by separating the application into different layers, including the domain, application, and infrastructure packages.

The repository is intended to demonstrate good programming practices, including encapsulation, inheritance, polymorphism, and abstraction. During development, GitHub Copilot will be used as an AI coding assistant to generate initial implementations of several classes. Every suggestion will be reviewed carefully, evaluated, and improved whenever necessary to ensure code quality and maintainability.

Version control is managed through Git using Conventional Commits. This approach provides a clear and consistent commit history, making the project easier to understand and maintain. The first commit establishes the project structure and prepares the repository for future development.

Future improvements will include unit testing, additional business logic, better documentation, and code reviews. The project also aims to apply SOLID principles and clean coding practices to create software that is easy to extend and maintain.

This repository represents the initial stage of a software development project and serves as a foundation for future assignments throughout the course. All source code, documentation, and project resources will be stored and maintained in this repository following professional software development standards.
