# TALLER_PROGRAMACION_2026_I_H

## Project Overview

This repository contains the initial structure of a Java project created for the Software Engineering Programming Workshop 2026. The main objective of this project is to apply object-oriented programming principles, software engineering practices, Git version control, and the use of artificial intelligence tools such as GitHub Copilot.

The project follows a standard Java project structure inspired by the Maven directory layout while using Gradle as the build automation tool. This organization helps maintain a clean architecture by separating the application into different layers, including the domain, application, infrastructure, repository, service, validation, and exception packages.

This project demonstrates the application of several software engineering concepts such as SOLID principles, object-oriented programming, exception handling, dependency inversion, functional interfaces, lambda expressions, method references, and unit testing. The repository includes examples of encapsulation, inheritance, abstraction, and polymorphism through a simple library management domain.

GitHub Copilot was used as an AI coding assistant to generate initial implementations of several classes. Every suggestion was carefully reviewed, evaluated, and improved whenever necessary to ensure code quality, readability, and maintainability. The project also includes a code review performed with GitHub Copilot to identify possible improvements and verify compliance with software development best practices.

Version control is managed through Git using Conventional Commits. This approach provides a clear and consistent commit history, making the project easier to understand and maintain. A Pull Request was also created to document the refactoring process and demonstrate a collaborative software development workflow.

Future improvements may include a database layer, graphical user interface, REST API integration, additional validation rules, and more comprehensive automated tests. The repository serves as a foundation for future assignments in the Software Engineering course while following professional development standards and clean architecture principles.
